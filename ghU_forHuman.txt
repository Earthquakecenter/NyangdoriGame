===================================================================
🚀 GitHub 연동 및 웹 배포 안내서 (사람을 위한 쉬운 설명서)
===================================================================

1. 어떤 작업을 완료했나요?
-------------------------------------------------------------------
컴퓨터 안에서만 혼자 돌려보던 내 게임 프로젝트를 인터넷 저장소(GitHub)와
연결하고, 친구나 지인에게 주소만 공유하면 스마트폰이나 컴퓨터 인터넷 창에서
곧바로 게임을 실행해 볼 수 있도록 '자동 웹 배포 시스템'을 구축했습니다.

- 내 GitHub 저장소: https://github.com/Earthquakecenter/NyangdoriGame
- 친구에게 공유하는 실제 게임 플레이 링크: https://earthquakecenter.github.io/NyangdoriGame/


2. 새롭게 추가된 파일과 설정은 무엇인가요?
-------------------------------------------------------------------
① `.github/workflows/deploy.yml` 파일 생성
   - 'GitHub Actions'라는 GitHub의 무료 로봇 일꾼에게 주는 작업 지시서입니다.
   - 내가 코드를 GitHub에 올릴 때마다, 로봇이 스스로 코드를 가져가서
     게임을 깔끔하게 완성품(dist 폴더)으로 조립한 뒤 인터넷 웹사이트로 띄워줍니다.

② Git 초기화 및 첫 커밋 & 업로드 (Push)
   - 프로젝트 폴더 안에 변경 기록을 추적하는 Git 장치를 설치하고,
     지금까지 작성된 게임 코드 전체를 안전하게 GitHub 원격 저장소로 복사해 올렸습니다.

③ GitHub Pages 활성화 (저장소 설정)
   - GitHub 저장소의 `Settings` -> `Pages` 메뉴에서 자동 배포 방식(`GitHub Actions`)을 켜서
     무료 웹 호스팅 주소를 열어두었습니다.


3. 앞으로 게임을 수정하고 웹에 반영하려면 어떻게 하나요?
-------------------------------------------------------------------
복잡한 터미널 명령어를 일일이 외우실 필요가 없습니다!

[가장 쉬운 방법 (AI에게 요청하기)]
- 저와 함께 게임 코드나 캐릭터를 수정한 후:
  "지금까지 수정한 내용 GitHub에 올려줘"라고 한마디만 말씀해 주시면,
  제가 알아서 저장(Commit)과 업로드(Push)를 해드립니다.

[직접 터미널로 올리고 싶을 때]
- 터미널(PowerShell)에서 아래 3줄만 순서대로 치면 끝납니다:
  1) `git add .`                      (수정한 파일들 장바구니에 담기)
  2) `git commit -m "수정 내용 요약"`   (기록 남기기)
  3) `git push origin main`           (GitHub로 전송하기)

업로드 후 1~2분 정도 지나면, 공유 주소(https://earthquakecenter.github.io/NyangdoriGame/)에
새로운 수정 사항이 자동으로 짠 하고 적용됩니다!

※ 팁: 방금 올렸는데 웹사이트에 예전 화면이 보인다면, 인터넷 창에서
       강력 새로고침(Ctrl + F5 또는 Shift + 새로고침)을 누르면 최신 버전이 바로 뜹니다.
