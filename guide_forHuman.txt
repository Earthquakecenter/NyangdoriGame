===================================================================
🎮 내 게임 프로젝트 안내서 (사람을 위한 쉬운 설명서)
===================================================================

1. 이 프로그램은 어떤 프로그램인가요?
-------------------------------------------------------------------
웹 브라우저에서 실행되는 간단한 2D 게임 기본 틀입니다.
어두운 회색 화면 정중앙에 '초록색 네모(플레이어)'가 하나 놓여 있고,
키보드의 W, A, S, D 키(또는 화살표 방향키)를 눌러 상하좌우 및 대각선으로
자유롭게 움직일 수 있습니다. 화면 끝(벽)에 닿으면 밖으로 나가지 않고 막힙니다.


2. src 폴더 안의 파일들은 각각 무슨 역할을 하나요?
-------------------------------------------------------------------
현재 `src` 폴더 안에는 총 3개의 자바스크립트(.js) 파일이 있으며,
식당으로 비유하면 '문 여는 직원', '매장 관리자', '주방 요리사'처럼 역할이 나뉘어 있습니다.

① src/main.js (게임을 처음 켜주는 스위치)
   - 역할: 인터넷 창(웹페이지)이 다 열렸을 때 "자, 이제 게임을 시작해!"라고
     신호를 보내는 가장 첫 번째 파일입니다.
   - 하는 일: 웹페이지 안에 있는 게임 화면 자리(`game-container`)를 찾아서
     그곳에 게임을 띄워줍니다.

② src/game/main.js (게임 환경 설정 파일)
   - 역할: 게임의 전체적인 규칙과 화면 크기를 정해주는 설정 파일입니다.
   - 하는 일:
     * 화면 크기를 가로 1024, 세로 768로 맞추고 화면 가운데에 보기 좋게 배치합니다.
     * 위에서 내려다보는 시점(탑다운 뷰)이라 아래로 떨어지는 '중력'을 0으로 껐습니다.
     * 현재 디버그 모드(`debug: true`)가 켜져 있어서, 사각형이 움직일 때
       어느 방향으로 얼마큼의 속도로 가는지 보여주는 초록색 선이 함께 표시됩니다.
       (선을 끄고 싶다면 이 파일에서 `debug: false`로 바꾸면 됩니다.)

③ src/game/scenes/Game.js (실제 게임 화면과 움직임 담당)
   - 역할: 화면에 실제로 보이는 초록색 사각형을 만들고, 키보드를 눌렀을 때
     움직이게 만드는 핵심 파일입니다.
   - 하는 일:
     * 처음 시작할 때(`create`):
       배경을 어두운 회색으로 칠하고, 화면 정중앙에 가로·세로 40 크기의
       초록색 사각형을 만듭니다. 그리고 W, A, S, D 키와 화살표 키를 인식하도록 준비합니다.
     * 게임이 돌아가는 동안 계속(`update`):
       1초에 수십 번씩 "지금 어떤 키가 눌려 있나?" 확인합니다.
       키가 눌린 방향으로 사각형을 속도 250으로 밀어주고, 키에서 손을 떼면 멈춥니다.
       (대각선으로 이동할 때 유독 빨라지지 않도록 속도를 일정하게 맞춰주는 계산도 들어 있습니다.)


3. 게임을 실행하고 끄는 방법
-------------------------------------------------------------------
[실행하기]
1) PowerShell(터미널)을 열고 프로젝트 폴더(`c:\dev\my-battlecats-game`)로 이동합니다.
2) 아래 명령어를 입력하고 엔터를 누릅니다:
   npm run dev-nolog
3) 인터넷 브라우저를 열고 주소창에 http://localhost:8080/ 을 입력하면 게임이 나옵니다!

[종료하기]
- 명령어를 입력했던 PowerShell 창에서 키보드의 `Ctrl + C`를 누르면 서버가 꺼집니다.
