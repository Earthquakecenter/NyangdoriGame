# GitHub 연동 및 CI/CD 자동 배포 가이드 (LLM 참조용)

## 1. Git & GitHub 저장소 개요
- **원격 저장소 URL**: `https://github.com/Earthquakecenter/NyangdoriGame.git`
- **배포 라이브 URL (GitHub Pages)**: `https://earthquakecenter.github.io/NyangdoriGame/`
- **기본 브랜치**: `main`
- **사용자 식별 정보 (Git Config)**:
  - `user.name`: `earthquakecenter`

---

## 2. CI/CD 워크플로우 설정 (`.github/workflows/deploy.yml`)
- **트리거 조건**:
  - `push`: `main` 브랜치에 코드가 푸시될 때 자동 실행
  - `workflow_dispatch`: GitHub 웹 콘솔에서 수동 트리거 지원
- **권한 (Permissions)**:
  - `contents: read`
  - `pages: write`
  - `id-token: write` (OIDC 기반 GitHub Pages 토큰 인증)
- **동시성 제어 (Concurrency)**:
  - `group: "pages"`, `cancel-in-progress: false` (배포 안정성 보장)
- **실행 환경 및 단계 (Jobs)**:
  1. **Build Job**:
     - Runner: `ubuntu-latest`
     - Node 환경 설정: Node.js `20` (`cache: 'npm'`)
     - 의존성 설치: `npm ci`
     - 프로덕션 번들 빌드: `npm run build-nolog` (`vite build --config vite/config.prod.mjs` 실행, 결과물은 `./dist`에 생성)
     - 배포 아티팩트 업로드: `actions/upload-pages-artifact@v3` (경로: `./dist`)
  2. **Deploy Job**:
     - Runner: `ubuntu-latest`, Needs: `build`
     - 환경: `github-pages`
     - 배포 액션: `actions/deploy-pages@v4`

---

## 3. 번들러 배포 정적 경로 호환성
- **Vite 설정 파일**: `vite/config.prod.mjs`
- **기본 상대 경로 설정**: `base: './'` 가 이미 명시되어 있어, 서브 디렉토리 형태인 GitHub Pages 호스팅(`/<저장소이름>/`) 환경에서도 자산(JS/CSS/이미지 등) 참조 경로 오류 없이 정상 로드됨.

---

## 4. 코드 갱신 및 배포 커맨드라인 패턴
향후 코드 수정 완료 후 원격 동기화 시 실행 절차:
```bash
git add .
git commit -m "<커밋 메시지>"
git push origin main
```
`main` 브랜치에 푸시되는 즉시 GitHub Actions 파이프라인이 구동되어 프로덕션 사이트로 자동 롤아웃됨.
